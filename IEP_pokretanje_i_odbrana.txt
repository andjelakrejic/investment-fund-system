3. KOMPAJLIRANJE SOLIDITY UGOVORA - NE MORAS!!!

Pre build-a director-service pokreni iz root-a projekta:

.\compile.ps1 -file_path "Voting.sol"

To treba da napravi:

solidity/output/Voting.abi
solidity/output/Voting.bin

Provera:

Get-ChildItem .\solidity\output

Treba da vidiš:
- Voting.abi
- Voting.bin

Director više ne kompajlira Solidity u runtime-u.

blockchain.py samo učitava:
- Voting.abi
- Voting.bin

Zato solc nije potreban unutar director poda tokom izvršavanja.

7. PORT-FORWARD

Otvori četiri posebna terminala i ostavi ih otvorene.

kubectl port-forward -n investment-fund service/authentication-service 5000:5000

kubectl port-forward -n investment-fund service/employee-service 5001:5001

kubectl port-forward -n investment-fund service/director-service 5002:5002

kubectl port-forward -n investment-fund service/blockchain 8545:8545

Od ovog trenutka koristiš:

authentication -> http://127.0.0.1:5000
employee       -> http://127.0.0.1:5001
director       -> http://127.0.0.1:5002
blockchain     -> http://127.0.0.1:8545

Ne koristiš NodePort brojeve za grader ako koristiš port-forward.


8. GRADER

U petom terminalu uđi u grader folder:

cd PUTANJA_DO\iep_testovi

Prvo pokretanje:

python -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r .\requirements-pytest.txt
pip install setuptools==80.9.0

Svaki sledeći put:

cd PUTANJA_DO\iep_testovi
.\.venv\Scripts\Activate.ps1

Kompletan grader:

pytest -q --type all `
  --authentication-url http://127.0.0.1:5000 `
  --jwt-secret development-secret-key-at-least-32-characters `
  --roles-field role `
  --employee-role employee `
  --director-role director `
  --with-authentication `
  --employee-url http://127.0.0.1:5001 `
  --director-url http://127.0.0.1:5002 `
  --with-blockchain `
  --provider-url http://127.0.0.1:8545 `
  --grade-report-file grade_report.json

9. PONOVNO POKRETANJE TESTOVA

Pre ponovnog grader run-a očisti test podatke.

Redis:

kubectl exec -n investment-fund deployment/order-storage -- redis-cli FLUSHALL

MongoDB:

kubectl exec -n investment-fund deployment/investment-database -- mongosh investment --eval "db.dropDatabase()"

MySQL - uzmi root password:

$MYSQL_PASSWORD = (kubectl exec -n investment-fund deployment/authentication-database -- printenv MYSQL_ROOT_PASSWORD).Trim()

Ostavi samo direktora:

kubectl exec -n investment-fund deployment/authentication-database -- mysql -uroot "-p$MYSQL_PASSWORD" -e "USE authentication; DELETE FROM user WHERE role != 'director';"

Zatim ponovo pokreni pytest.

Za čišćenje baza ne moraš da restartuješ port-forward terminale.

13. AKO SE POJAVI ErrImageNeverPull

To znači da Kubernetes ne vidi lokalni Docker image koji deployment pokušava da koristi.

Provera:

kubectl get pods -n investment-fund
kubectl describe pod -n investment-fund IME_PODA

Ako imate .tar sa image-ima, image mora da bude učitan u runtime koji Kubernetes koristi.

Moguća varijanta na Linux/VM node-u:

sudo ctr -n k8s.io images import iep-images.tar

Tačan način zavisi od laboratorijskog okruženja.

U običnom Windows PowerShell-u nemoj nasumično koristiti sudo ctr.


14. OFFLINE SOLIDITY NA ODBRANI

Ako na odbrani nema interneta i dobiješ Docker image za Solidity kao .tar:

docker load -i PUTANJA_DO_SOLC_IMAGE.tar

Provera:

docker images

Mora da postoji:

ethereum/solc   0.8.18

Zatim:

.\compile.ps1 -file_path "Voting.sol"

Time lokalno dobijaš:
- Voting.abi
- Voting.bin

Pa tek onda build-uješ director:

docker compose -p projekat -f .\compose.yaml build director-service

Redosled:

docker load solc image
        ↓
compile.ps1
        ↓
Voting.abi + Voting.bin
        ↓
build director
        ↓
Kubernetes
        ↓
grader

py-solc-x može da ostane u requirements.txt, ali više nije deo runtime kompajliranja.


15. VAŽNO

- Ne postoji --with-kubernetes.
- Blockchain se uključuje sa --with-blockchain.
- Provider se zadaje sa --provider-url.
- Authentication se uključuje sa --with-authentication.
- Za završnu proveru koristi --type all.
- Ne pokreći grader više puta bez čišćenja baza.
- Posle brisanja namespace-a sva četiri port-forward terminala moraju ponovo da se pokrenu.
- Ako koristiš port-forward, ne trebaju ti NodePort brojevi u grader komandi.
- py-solc-x nije isto što i solc.
- solcx je Python wrapper.
- solc je pravi Solidity compiler.
- compile.ps1 koristi ethereum/solc:0.8.18.
- Voting.abi + Voting.bin moraju da uđu u director image.
- docker compose build pravi novi image.
- kubectl rollout restart samo restartuje Kubernetes pod; zato uvek proveri da je pod stvarno dobio novi kod.
- Ako /decision vraća 500, prvo:
  kubectl logs -n investment-fund deployment/director-service --tail=100

  98 passed
